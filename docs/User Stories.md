# User Stories

1. Recipes Storage
   1. As a user I want to be able to save my recipes and assign them a name
   2. As a user I want to be able to group variations of the same recipe together and give the group a name
   3. As a user I want to be able to store which ingredients each of my recipes use
   4. As a user I want to be able to store the instructions for my recipes
   5. As a user I want to be able to store how much of the ingredients is required for my recipes
   6. As a user I want to be able to provide the nutrition facts for the ingredients I use
   7. As a user I want to be able to store multiple variants of the same ingredient
   8. As a user I want to be able to reuse ingredients (only provide the nutrition facts once)
   9. As a user I want to be able to provide the cost of the ingredients I use at different points in time
   10. As a user I want to be able to use the application without needing to provide nutrition facts for my ingredients (those features can remain with no data)
   11. As a user I want to be able to use the application without needing to provide ingredient prices (those features can remain with no data)
   12. As a user I want to be able to provide only the nutrition facts I am interested in for my ingredients
   13. As a user I want to be able to edit the nutrition facts for my ingredients later (for example, to provide additional information)
   14. As a user I want to be able to edit the historical cost of my ingredients in case I have data from the past or made a mistake
2. Interfacing
   1. As a user I want to be able to export my recipes to a file
   2. As a user I want to be able to export my ingredients to a file
   3. As a user I want to be able to import recipes from a file
   4. As a user I want to be able to import ingredients from a file
3. Statistics
   1. As a user I want to be able to view how many calories are in each portion of my recipes
   2. As a user I want to be able to view how much of various nutrients are in each portion of my recipes (at least the ones on the nutrition facts)
   3. As a user I want to be able to calculate how much each portion of my recipes cost
   4. As a user I want to be able to see the historical cost of my recipes (by portion) with the data I have provided over time
   5. As a user I want to be able to see the historical cost of my ingredients with the data I have provided over time
4. Search
   1. As a user I want to be able to search my recipes by group
   2. As a user I want to be able to search my recipes by name
   3. As a user I want to be able to search my ingredients by name
   4. As a user I want to be able to find which recipes I can cook with a certain list of ingredients (the ones I have)
